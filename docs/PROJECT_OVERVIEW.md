# Lume

## Vision

Lume is an open source ERP platform for small businesses.

The project aims to provide a modern, modular and maintainable business
management system built as a real-world reference application for
Angular and Spring Boot.

## Goals

-   Learn Angular through a real product.
-   Learn Spring Boot and modern backend architecture.
-   Build a production-quality open source project.
-   Encourage community contributions.
-   Become a reference project for clean architecture and software
    engineering.

## Target Audience

-   Small businesses
-   Retail stores
-   Markets
-   Restaurants
-   Bakeries
-   Cafeterias
-   Service providers
