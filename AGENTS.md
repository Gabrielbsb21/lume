# Repository Guidelines

## Git conventions

- Branch names must follow Conventional Commits semantics using
  `<type>/<short-kebab-case-description>`.
- Do not add an agent or tool prefix such as `codex/` to branch names.
- Use one of the standard types: `feat`, `fix`, `docs`, `style`, `refactor`,
  `perf`, `test`, `build`, `ci`, `chore`, or `revert`.
- Commit messages must follow `<type>(<optional-scope>): <description>`.

Example: `chore/update-project-dependencies` with commit
`chore(deps): update project dependencies`.
